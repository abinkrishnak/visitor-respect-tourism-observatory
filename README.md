# Visitor Respect & Sustainable Tourism Observatory

A responsible AI and data product that supports sustainable tourism through
transparent official statistics, carefully validated AI-derived discussion
signals, and voluntary visitor-respect learning.

## Why this project exists

Tourism creates jobs, cultural exchange, and economic value. It can also create
pressure on public spaces, heritage, the environment, and residents when it is
not managed responsibly.

This project helps users understand tourism trends, learn respectful visitor
behaviour, and explore transparent evidence.


## Version 0.1

Planned work:

- Voluntary visitor-respect micro-learning quiz
- International case study: Italy

## Evidence labels

| Label | Meaning |
|---|---|
| Official statistic | Published by an official authority, such as STB or SingStat |
| Derived indicator | A transparent calculation from documented fields |
| Model-derived signal | A validated AI output from a defined public-discussion sample |
| Scenario / pilot | A hypothetical calculation or voluntary-learning result |

## Important limitations

- This project does not rank nationalities or make visa decisions.
- Online discussion is not representative of all visitors or residents.
- AI outputs are presented with model evaluation and limitations.
- Every published metric will include its source and data date.

## Project status

In development — Singapore pilot.

## Planned responsible AI component

The next project phase will build a human-validated NLP classifier for broad
tourism-discussion themes. It will use a lawful, defined sample of public
discussion, documented annotation rules, privacy safeguards, and held-out model
evaluation.

The AI component will not classify people, nationalities, or countries. It will
not make visa, immigration, enforcement, or risk decisions.
