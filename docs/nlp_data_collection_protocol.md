# NLP Data Collection Protocol

## Project

Visitor Respect & Sustainable Tourism Observatory

## Purpose

This future NLP component will identify broad tourism-discussion themes in a
defined sample of lawful public online discussion.

The purpose is to understand discussion patterns that may help generate
questions for tourism research and visitor education. It is not intended to
judge visitors, nationalities, countries, or individuals.

## Research question

Which neutral tourism-related themes appear in a defined English-language
public-discussion sample related to Singapore tourism?

## Proposed themes

- Crowding and access
- Visitor respect and etiquette
- Environment and cleanliness
- Cost and displacement
- Positive coexistence
- Unclear or no relevant theme

## Proposed data source

Reddit public content accessed only through an approved official API and in
accordance with the platform's current terms, rate limits, and data-use rules.

No data will be collected until platform access, terms, permissions, and
retention obligations are checked again.

## Proposed sampling approach

- Geography/topic: Singapore tourism-related discussion
- Language: English in Version 1
- Time period: To be documented before collection
- Search communities and queries: To be documented before collection
- Target sample size: Determined by permitted API access and annotation capacity,
  not an arbitrary large number
- Unit of analysis: One eligible public post or comment

## Inclusion criteria

Include text only when it is:

1. Publicly available through permitted access;
2. Relevant to Singapore tourism, a visitor experience, a public/cultural space,
   tourism operations, or a tourism-related impact;
3. Written in English for Version 1; and
4. Long enough to contain meaningful context.

## Exclusion criteria

Exclude:

- Usernames, profiles, personal contact details, and account metadata;
- Deleted or inaccessible content;
- Content with unnecessary personal or sensitive information;
- Text unrelated to tourism;
- Duplicates, reposts, spam, and empty text;
- Content used in a way that violates platform terms.

## Data minimisation

The project will collect only the minimum required fields:

- Anonymous internal document ID
- Collection date
- Publication month/year
- Text needed for private analysis
- Community/query label, where permitted
- Human theme labels
- Model output and confidence, after modelling

Raw public-platform text and usernames will not be published in the GitHub
repository or public website.

## Privacy and publication rules

- Do not publish usernames, profiles, URLs, or raw text.
- Do not use data to infer identity, residence, nationality, ethnicity, gender,
  age, or visitor status.
- Publish only permitted, aggregated results.
- Suppress small aggregate cells where necessary.
- Follow platform deletion, storage, and retention requirements.

## Known limitations

- Public online discussion is not a survey and does not represent all visitors,
  residents, or Singapore society.
- English-only analysis excludes other languages.
- Search queries and selected communities influence the sample.
- Media events and platform changes can affect discussion volume.
- Theme trends cannot prove tourism caused a discussion pattern.

## Approval checklist before collection

- [ ] Current platform terms reviewed and recorded
- [ ] API access and permitted use confirmed
- [ ] Communities, search queries, and date range documented
- [ ] Retention/deletion obligations reviewed
- [ ] Annotation guide completed
- [ ] Raw-data storage location secured and excluded from GitHub
- [ ] Supervisor or relevant reviewer consulted if required
