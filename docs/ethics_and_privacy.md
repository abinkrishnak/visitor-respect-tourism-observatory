# Ethics and Privacy

## Purpose

This project supports respectful travel and transparent tourism analysis. It is
not a tourist-risk, nationality-ranking, visa-decision, immigration, policing,
or enforcement system.

## Current data

The current version uses official aggregate Singapore tourism data only. It does
not collect personal data through the website.

## Future online-discussion analysis

Before any public-platform data is collected, this project will:

- confirm current platform terms and permitted access;
- write a collection protocol;
- minimise fields collected;
- avoid publishing usernames, profiles, or raw post text;
- publish only aggregated findings where permitted;
- document sample bias, language limitations, and model performance;
- allow for deletion/retention obligations where applicable.

## Fairness principles

The project will not label nationalities, ethnicities, countries, or people as
good, bad, respectful, or risky. Any future model will classify discussion
themes, not people.

## Limits of AI

AI outputs can be wrong, biased, incomplete, or affected by language and
sampling choices. Model results will be treated as limited discussion signals,
not as facts about all visitors or residents.
